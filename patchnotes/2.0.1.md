# Witchbound 2.0.1

A click fix for Minecraft 26.3.

## Fixed (Minecraft 26.3)

- **The Coven screen ignored clicks.** Left-clicking a tab or a button, such as Strike on a pact, did nothing, so
  nothing in the screen could be used. Tabs and buttons respond to left-click again.

Minecraft 26.3 numbers mouse buttons differently from earlier versions (left is 1, right is 3), and the Coven screen
read the raw number. It now translates it the same way Minecraft's own inventory screens do. 1.21.1, 26.1.2 and 26.2
are unchanged apart from the version number. No gameplay, config or save changes.
