# Witchbound 2.0.2

Witchbound now runs on Minecraft 1.20.1.

## New

- **Minecraft 1.20.1 is supported, on Fabric and on Forge.** The huts, the Coven Witches, pacts, hexes, errands, the
  Grimoire, Witch Bottle and Poppet, the Coven screen and the advancements are all there. Fabric needs Fabric API.

1.20.1 has fewer player attributes than newer versions, so a few pact and hex effects are done a different way there:
the jump changes use a hidden Jump Boost, step height and Raven's lighter fall are applied each tick, and on Fabric
Raven and Clumsy Fingers change how far you can reach blocks (on Forge they also change how far you can hit). They
should feel the same in play.

## Changed

- **Minecraft 26.1.2 is no longer supported.** Witchbound 2.0.2 is built for 1.20.1, 1.21.1, 26.2 and 26.3. Worlds on
  26.1.2 can keep using 2.0.1.

1.21.1, 26.2 and 26.3 are unchanged apart from the version number. No gameplay, config or save changes there.
